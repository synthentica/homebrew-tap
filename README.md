# synthentica/tap

Homebrew casks for apps by synthentica.

```sh
brew install --cask synthentica/tap/kumquat
```

| Cask | App |
| --- | --- |
| `kumquat` | [Kumquat](https://github.com/synthentica/kumquat): drag a file, hold a key, drop it on a format. A free, native, offline file converter for macOS. |
